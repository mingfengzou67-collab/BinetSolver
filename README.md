# 比耐公式求解器（理论力学 · 有心力轨道）

文件：`BinetSolver.m`（一个文件搞定，不需要任何工具箱）

## 它解的是哪个式子

质点在有心力 `F(r)` 下运动，令 `u = 1/r`，比耐公式是

```
d²u/dθ² + u = - F(1/u) / ( m h² u² )
```

其中 `m` 是质量，`h = r²·(dθ/dt)` 是**单位质量的角动量**，是个常数；`F > 0` 是斥力，`F < 0` 是引力。

注意它是个**关于角度 θ 的二阶方程**，未知函数是 `u(θ)` 而不是 `r(t)`。这也是为什么脚本里用 `ode45` 时自变量给的是 θ。

## 怎么用（三步）

1. 把 `BinetSolver.m` 所在的文件夹设为 MATLAB 的当前文件夹（或直接把文件夹拖进 MATLAB）。
2. 打开 `BinetSolver.m`，只需要改文件最上面这两行：
   ```matlab
   exampleId = 1;      % 1、2、3、4 选一个题目
   animate   = true;   % 要不要播放质点运动动画
   ```
3. 按 `F5`（或者点工具栏的绿色三角）。命令行会列出题目让你按回车确认，然后自动弹图。

## 四个例子分别在讲什么

| exampleId | 内容 | 会看到什么 |
|---|---|---|
| 1 | 平方反比引力 `F = -k/r²` | 椭圆轨道，且与理论解完全重合（开普勒第一定律） |
| 2 | 同样的力，但初速度更大 | 双曲线轨道，质点逃逸到无穷远 |
| 3 | 平方反比力 + 微扰项 `-α/r⁴` | 轨道不再闭合，近力心点一圈圈前移（进动） |
| 4 | **反着用**：已知轨道 r(θ)，反推力 F(r) | 反推出的 `F·r²` 是常数 −1，即力确实是 `∝ -1/r²` |

例子 1、2 跑完会给出数值结果和理论公式 `e = √(1 + 2Emh²/k²)` 的对照，可以当"答案对不对"的自检。

## 想做自己的题

打开文件最末尾的 `examples()` 函数，照着"例 1"改。关键四个量：

- `Ffun`：力，注意用 `./` 和 `.^`，例如 `@(r) -1 ./ r.^2` 表示 `F = -1/r²`。
- `Vfun`：势能（满足 `F = -dV/dr`），只用来画图时检查能量守恒，懒得写就随便给个函数。
- `r0`、`vt0`：初始距离和初始横向速度，脚本自动算出 `h = r0·vt0`。
- `vr0`：初始径向速度，从最近点/最远点出发就填 0。

初值由公式自动转换，不用自己推：

```
u(0) = 1/r0 ,   du/dθ|₀ = -vr0 / h        （因为 dr/dt = -h·du/dθ）
```

判断轨道是椭圆还是双曲线，看能量 `E = ½m(vr² + vt²) + V(r)`：`E < 0` 是椭圆，`E = 0` 是抛物线，`E > 0` 是双曲线。脚本会把 E 打印出来。

## 常见问题

- **图里曲线跑出画框**：开放轨道（逃逸）本来就会跑到无穷远，脚本会自动在 `r = 8·r_min` 处截断，图题里写了截断半径。
- **想算更远/更久**：改对应例子的 `thetaMax`（单位是弧度，`2π` 就是一圈）。
- **动画怎么关**：把参数区的 `animate` 改成 `false`。
- **命令行中文是乱码**：那是 MATLAB 命令窗口的编码问题，不影响计算；如果文件里的中文注释显示成乱码，用"另存为"把它存成 UTF-8 编码即可。
- **`ode45` 报错或者结果很怪**：通常是力在 `r → 0` 时发散太厉害（比如 `F ∝ -1/r³`），数值方法会失效，这是物理上的奇点，不是脚本的锅。
- **版本要求**：MATLAB R2017b 及以上（用到了 `islocalmin`）；固定浅色主题的 `theme` 函数只有 R2025a 以后才有，老版本会自动跳过，不影响运行。
